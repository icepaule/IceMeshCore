IceMeshCore

Aufbau eines eigenen, funkbasierten MeshCore-LoRa-Mesh-Netzwerks mit LilyGo-Hardware – abhoerresistent von Mobilfunk und Internet, mit Anbindung an Home Assistant zum Senden und Empfangen von Nachrichten.

EU 869.618 MHz · SF10 · Ende-zu-Ende-verschluesselt
Ueberblick Architektur Hardware Tech-Stack Quickstart

Ueberblick

IceMeshCore ist eine Schritt-fuer-Schritt-Doku- und Konfigurationssammlung fuer den Aufbau eines privaten MeshCore-LoRa-Mesh-Netzwerks. Statt Mobilfunk oder WLAN tauschen die Geraete Nachrichten direkt per LoRa-Funk aus – jedes Client- oder Repeater-Geraet leitet dabei Pakete fuer andere Knoten weiter und vergroessert so die Reichweite des Netzes. Ueber ein WiFi-Gateway wird das Mesh zusaetzlich an Home Assistant angebunden, sodass Nachrichten auch bequem per Tablet-Dashboard gesendet und empfangen werden koennen.

Das Repository selbst enthaelt keinen MeshCore-Firmware-Quellcode, sondern PlatformIO-Konfigurationsvorlagen, Build-/Flash-Skripte, Home-Assistant-Konfigurationsbeispiele und ausfuehrliche deutsch-/englischsprachige Anleitungen fuer jeden Einrichtungsschritt.

Privates Funknetz

Kommunikation komplett ohne Internet oder Mobilfunk – reines LoRa-Mesh auf 869,618 MHz im europaeischen Frequenzband.

Ende-zu-Ende-Verschluesselung

Alle Mesh-Nachrichten sind Public-Key-verschluesselt; Repeater-Adminzugriff ist zusaetzlich per Passwort geschuetzt.

Home-Assistant-Integration

WiFi-Gateway spricht TCP:5000 mit der meshcore-ha-Integration – Dashboards, Automationen und optionale MQTT-Bruecke inklusive.

Reichweiten-Erweiterung

Ein dedizierter Repeater mit OLED-Statusdisplay leitet Pakete zwischen Knoten weiter, die sich sonst nicht direkt erreichen wuerden.

Architektur

Drei Geraetetypen bilden das Mesh: ein portabler Client mit Tastatur und Karten (T-Deck), ein staionaerer Repeater mit OLED-Statusanzeige (T-Beam Supreme) und ein WiFi-Gateway, das die Bruecke ins Heimnetz und zu Home Assistant schlaegt (T-Beam). Der Gateway-Knoten ist gleichzeitig auch ein vollwertiger Mesh-Teilnehmer und leitet Pakete weiter.

Die Kommunikationskette in Kurzform: T-Deck → T-Beam Supreme (verschluesseltes LoRa-Paket), T-Beam Supreme → T-Beam (Relay zur Reichweitenverlaengerung), T-Beam → Heimnetz (WiFi/TCP:5000), Heimnetz → Home Assistant (meshcore-ha-Integration als TCP-Client), Home Assistant → Nutzer (Dashboard, Push-Benachrichtigung, MQTT).

Quickstart

Grobablauf laut Setup-Guide: Repo klonen, MeshCore-Quellcode daneben klonen, Config-Vorlage kopieren und anpassen, Firmware bauen und flashen.

git clone https://github.com/icepaule/IceMeshCore.git
git clone https://github.com/meshcore-dev/MeshCore.git

# WiFi-Gateway (T-Beam SX1276) bauen und flashen
cp IceMeshCore/configs/tbeam_sx1276_wifi.ini \
   MeshCore/variants/lilygo_tbeam_SX1276/platformio.ini
# WIFI_SSID / WIFI_PWD in der Datei anpassen
./IceMeshCore/scripts/build-tbeam.sh /dev/ttyACM0

# Repeater (T-Beam Supreme SX1262) bauen und flashen
cp IceMeshCore/configs/tbeam_supreme_sx1262_repeater.ini \
   MeshCore/variants/lilygo_tbeam_supreme_SX1262/platformio.ini
# ADVERT_NAME / ADMIN_PASSWORD in der Datei anpassen
./IceMeshCore/scripts/build-tbeam-supreme.sh /dev/ttyACM0

# T-Deck per Web-Flasher oder Skript
./IceMeshCore/scripts/flash-tdeck.sh /dev/ttyACM0

Anschliessend in Home Assistant ueber HACS die meshcore-ha-Integration installieren und per TCP mit dem Gateway (Port 5000) verbinden. Details siehe docs/setup-guide.md im Repository.
